BlockMaestro: Enabling Programmer-Transparent Task-based Execution in GPU Systems

Amirali Abdolrashidi, Hodjat Asghari Esfeden, Ali Jahanshahi, Kaustubh Singh, Nael Abu-Ghazaleh, and Daniel Wong

The 48th ACM/IEEE International Symposium on Computer Architecture (ISCA), June 2021.

PDF
Emerging GPU workloads contain hundreds or thousands of kernel launches with inter-kernel data dependencies that cause high launch overhead, synchronization stalls, and under-utilization. BlockMaestro is a software-hardware solution combining command queue reordering, kernel-launch-time static analysis, kernel pre-launching, and runtime hardware dependency resolution to enable programmer-transparent thread-block-level task execution, achieving 51.76% average speedup (up to 2.92×) on data-dependent benchmarks with minimal hardware overhead.

BOW: Breathing Operand Windows to Exploit Bypassing in GPUs

Hodjat Asghari Esfeden, Amirali Abdolrashidi, Shafiur Rahman, Daniel Wong, and Nael Abu-Ghazaleh

The 53rd IEEE/ACM International Symposium on Microarchitecture (MICRO), October 2020.

PDF
Frequent accesses to multi-bank GPU register files incur major dynamic power overhead and bank-conflict delays. Observing strong temporal locality in register accesses within short instruction windows, we propose Breathing Operand Windows (BOW) — an enhanced GPU pipeline, operand collector organization, and compiler optimization that bypasses both unnecessary register file reads and writes. BOW reduces register file dynamic energy consumption by 55% and improves overall performance by 11% with only 12 KB of additional storage (~4% of RF size).

Locality-aware GPU Register File

Hyeran Jeon, Hodjat Asghari Esfeden, Nael Abu-Ghazaleh, Daniel Wong, and Sindhuja Elango

IEEE Computer Architecture Letters (CAL), November 2019.

PDF
We propose a locality-aware GPU register file that enables inter-warp data sharing for memory-intensive deep learning and big-data workloads without relying on small shared memory. Through an extended register mapping mechanism, warps opportunistically share or reconstruct operands already resident in physical registers, achieving over 2× speedup and up to 57% register space savings.

CORF: Coalescing Operand Register File for GPUs

Hodjat Asghari Esfeden, Farzad Khorasani, Hyeran Jeon, Daniel Wong, and Nael Abu-Ghazaleh

The 24th ACM International Conference on Architectural Support for Programming Languages and Operating Systems (ASPLOS), Providence, RI, April 2019.

PDF Slides Poster Video
CORF is a compiler-assisted Coalescing Operand Register File that combines reads to multiple narrow-width operands required by a single GPU instruction into one physical register read via register packing. Extending this to mutually exclusive sub-banks (CORF++) via bipartite edge-frustration graph coloring reduces RF dynamic energy by 17% and improves IPC by 9%.

Virtual Persistent Processor Specialization (VPPS) enables on-chip in-register caching of recurrent weight matrices during the training of dynamic neural networks on GPUs. RegMutex: Inter-Warp GPU Register Time-Sharing

Farzad Khorasani, Hodjat Asghari Esfeden, Amin Farmahini-Farahani, Nuwan Jayasena, and Vivek Sarkar

The 45th ACM/IEEE International Symposium on Computer Architecture (ISCA), Los Angeles, CA, June 2018 (16.9% acceptance rate).

PDF Slides Video
Static worst-case register allocation leaves large portions of GPU register files under-utilized. RegMutex (Register Mutual Exclusion) is a compiler-hardware co-design that splits architected registers into a dedicated base set and a time-shared extended set across warps, increasing occupancy and cutting execution cycles by up to 23% on register-heavy GPU kernels.

RIC: Relaxed Inclusion Caches for Mitigating LLC Side-Channel Attacks

Mehmet Kayaalp, Khaled N. Khasawneh, Hodjat Asghari Esfeden, Jesse Elwell, Nael Abu-Ghazaleh, Dmitry Ponomarev, and Aamer Jaleel

The 54th ACM/EDAC/IEEE Design Automation Conference (DAC), Austin, TX, June 2017.

PDF Slides
Side-channel attacks on Last Level Caches (LLCs) rely on evicting critical victim data from private caches via inclusive back-invalidations. Relaxed Inclusion Caches (RIC) selectively relaxes inclusion for protected lines, blocking LLC eviction-based leakage while retaining snoop-filtering benefits and improving performance by ~10% with minimal cache hardware changes.
